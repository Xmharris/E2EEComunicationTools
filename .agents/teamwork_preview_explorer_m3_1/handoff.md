## 2. Logic Chain
1. **End-to-End Cryptography Verification**:
   * `MessageManager` constructs an X25519 key pair locally and registers only the public key PEM with the backend (`MessageManager.kt` lines 22-23, 43).
   * For direct messaging and DM meetings/files, the client retrieves the peer's public key from the backend and derives a shared key locally using ECDH + HKDF-SHA256 key agreement (`MessageManager.kt` lines 75-76, 93-94, 176-177, 230-231). The private key never leaves the client.
   * For spaces, a random 256-bit symmetric `spaceKey` is generated by the creator (`MessageManager.kt` line 64) and distributed to space members encrypted under their ECDH shared keys (`MessageManager.kt` lines 75-78).
   * Meeting details (`MeetingMetadata`) are encrypted client-side using either the space key or the ECDH shared key prior to transmission (`MessageManager.kt` lines 171-179).
   * Shared files are encrypted using a fresh, random 256-bit `fileKey` (`MessageManager.kt:210`). The `fileKey` is then encrypted under the space key or the ECDH shared key and bundled into the `FileMetadata` object, which itself is encrypted under the channel key (`MessageManager.kt:233-242`).
   * The backend database schema (`main.py` lines 23-60) contains no private keys, plaintext message/meeting payloads, or plaintext files/file keys.
   * *Conclusion*: Therefore, all meetings and shared files are fully end-to-end encrypted client-side, preventing eavesdropping by the backend or any transport-layer intermediary.
2. **Robust Input Validation Verification**:
   * Meeting scheduling validates that `title`, `time`, and `location` are not blank (`MessageManager.kt` lines 151-153).
   * The date-time format of a meeting's `time` is normalized and validated against `DateTimeFormatter.ISO_DATE_TIME.parse()` (`MessageManager.kt` lines 156-166). Invalid formats throw `IllegalArgumentException`.
   * File sharing validates that the file to upload is not empty (`MessageManager.kt` line 208). Attempting to share an empty byte array throws `IllegalArgumentException("Cannot upload empty file")`.
   * *Conclusion*: Critical fields are validated locally before any encryption or network request is initiated.
